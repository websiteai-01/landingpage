# VOLT — Electric Mobility Landing Page

Landing page kendaraan listrik dengan gaya visual otomotif premium, terinspirasi dari desain minimalis situs otomotif modern. Dibuat dengan HTML, CSS, dan JavaScript vanilla tanpa proses build.

## Fitur
- Layout full-screen dengan beberapa section
- Navigasi sticky yang berubah saat halaman digulir
- Menu responsif untuk perangkat mobile
- Tombol interaktif dan smooth scrolling
- Foto latar eksternal dari Unsplash
- Bahasa Indonesia

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages:
1. Buka **Settings → Pages** pada repository.
2. Pada **Build and deployment**, pilih **Deploy from a branch**.
3. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.

Tunggu proses deployment selesai. URL situs akan tampil di halaman GitHub Pages.

> VOLT adalah konsep desain fiktif, bukan situs resmi Tesla. Spesifikasi kendaraan yang ditampilkan adalah ilustrasi.
